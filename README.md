# Dubml documentation

This is the documentation website for the [dubbo-mesh](https://github.com/apache/dubbo-kubernetes) project, built with MkDocs and a local theme (`theme/`).

## Start and run

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m mkdocs serve
```
