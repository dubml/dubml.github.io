    Documentation¶

    Transit 可以通过两种方式进行部署。请选择您的部署类型以查看相关文档。

    transit standalone binary
    Standalone Binary

    在本地机器或服务器上将 transit 作为独立二进制文件或在 Docker 中运行。适用于开发、测试和简单部署。
    transit on Kubernetes
    Kubernetes

    使用内置控制平面和 Gateway API 在 Kubernetes 上部署和动态配置 transit。
